# Mascot Mayhem

A zero-dependency personal-use fantasy football decision app.

## Run
Double-click `index.html`. It works locally in a modern browser with no server and no install.

## Concept
Pick two NFL teams and let original mascot-inspired combatants settle the decision in a randomized animated fight. The outcome is intentionally 50/50 and unrelated to real football odds.

## Special interpretations
- Browns: Lake Erie Brownie — a scrappy mythic elf/brownie rather than a literal brown object.
- Steelers: Steel-Mill Golem — a living foundry machine built from Pittsburgh steel.
- Packers: Frozen Cheese Brute.
- Chargers: Living Lightning Bolt.
- Jets: Runway Fighter Jet.
- Giants: Gotham stone giant.
- 49ers: Gold-rush prospector.
- Patriots: Colonial brawler.
- Commanders: Capital commander.
- Titans: mythological titan.

No official team logos or mascot artwork are bundled.
